For a long time, the ability to create software depended on knowing a programming language and having the experience to use it. That barrier was never completely insurmountable, but it did limit who could turn an idea into a working application.

AI is changing that relationship.

---

And I see it as a huge opportunity, not because programming has lost its value, but because we can now expand the number of people who take part in creating software.

Not everyone needs to know how a database works, how an application is structured, or how an API is implemented. Many people just need a tool that solves a specific problem.

And if they can build it, test it, and use it, why should we require them to learn how to program first?

That doesn't mean we should stop teaching programming. It means we need to recognize that **creating software and writing code are not quite the same activity**.

A person can create software without writing code. A developer can use AI to write code without ceasing to practice their craft.

Both things can coexist. **And perhaps that is AI's real potential: that creating software stops being a capability reserved for those who know how to program.**
